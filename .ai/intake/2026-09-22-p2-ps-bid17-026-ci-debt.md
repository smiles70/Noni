# PS-BID17-026 — CI debt: bundle-size budget + backend black failures on main

**Date:** 2026-09-22 · **Priority:** P2 · **Status:** implementing
**Skill check:** `error-taxonomy` invoked — `bundle-overflow` + `black-format`
(auto-fix category for black; escalate for bundle). Jev gate on fix path.

## Problem statement

CI fails on every `main` push: (1) `bundle-size` gate — index chunk
100.08 kB gz vs 100 kB budget (ADR-0013); (2) `black --check backend/` —
one file unformatted (`backend/tests/test_curriculum_kb.py`, PS-020).
Both pre-date the forms restyle; both make every deploy look red.

## Cross-workspace assessment

- `Noni`: 11 workflows — ci.yml gates on build+bundle+black.
- `mynaani-crm`: 5 workflows — no bundle gate (backend app).
- `n8n-help-flow`: mirrors Noni's deploy workflows — same debt pattern
  likely dormant there; out of scope for this ticket.

## Root cause (confirmed)

- Black: single-file drift, zero blast radius.
- Bundle: index chunk = eager boot code only (react-dom, router,
  AuthProvider, App shell — all correctly non-lazy). `vite.config.ts`
  has NO `manualChunks` — every eager dep lands in `index`. The chunk
  is structurally fat, not bloated by app code.

## Jev gate (jev-1.13.0)

- black fix safe: 0.93
- raise-budget-via-ADR defensible: 0.37 — weak
- rushed code-split justified by 0.08 kB: 0.43 — no
- investigate composition first: 0.86
- **pick: investigate-first → vendor split**
- urgency: this-sprint (1.2)

## Fix

1. `black backend/tests/test_curriculum_kb.py` — auto-fix.
2. `vite.config.ts` `manualChunks`: split `react`, `react-dom`,
   `react-router-dom` into a `vendor` chunk (keeps each under 100 kB gz;
   index drops to app-shell only). No budget change, no ADR needed —
   the ADR's intent (per-chunk, encourage splitting) is honored.

## Edge cases

- Vendor chunk must itself stay <100 kB gz (react-dom ~59 gz + router
  ~25 gz — verified margin).
- HTTP/2 parallel fetch on Cloudflare — no waterfall penalty.
- Black reformat is whitespace-only; unit tests pin behavior.

## Acceptance criteria

- [ ] `black --check backend/` clean.
- [ ] `npm run bundle-size` green, all chunks <100 kB gz.
- [ ] CI green on next main push.
- [ ] No eager/lazy boundary change (routes stay lazy).
